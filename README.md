## ▶️ Getting Started

Clone the project:

```bash
git clone https://github.com/ziad-elgaraihe/portfolio.git
```

Install dependencies:

```bash
flutter pub get
```

Run the project:

```bash
flutter run -d chrome
```

Build for production:

```bash
flutter build web --release
```
